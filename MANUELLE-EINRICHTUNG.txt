==========================================================================
  AURELUNE STUDIO – Manuelle Einrichtung (Windows 10/11)
==========================================================================

Normalerweise erledigt "Aurelune-Studio-Setup.exe" ALLES automatisch.
Diese Anleitung ist für alle, die jeden Schritt selbst machen oder
prüfen möchten, was der Installer verändert.

--------------------------------------------------------------------------
 WAS DER AUTOMATISCHE INSTALLER MACHT
--------------------------------------------------------------------------
 1. Python 3.12 (nur wenn kein Python 3.10–3.13 vorhanden ist)
 2. Microsoft WebView2 (nur wenn nicht vorhanden)
 3. App nach  %LOCALAPPDATA%\Programs\Aurelune Studio
 4. VB-CABLE Treiber (nur wenn nicht vorhanden) + Einstellungen:
      - CABLE Input & CABLE Output auf 48000 Hz, 24 Bit
      - Lautstärke beider CABLE-Geräte 100 %, nicht stumm
      - Windows-Kommunikation: "Nichts unternehmen" (kein Leiser-Stellen)
      - deaktivierte CABLE-Geräte werden wieder aktiviert
      - dein bisheriges Ausgabegerät (z. B. "SteelSeries Sonar - Gaming")
        wird als Hauptlautsprecher von Aurelune gespeichert
 5. Komponenten: numpy, sounddevice, pywebview (in eigener Umgebung)
 6. Startmenü, Desktop-Verknüpfung, Autostart, Eintrag unter "Apps"

--------------------------------------------------------------------------
 SCHRITT 1 – Python installieren
--------------------------------------------------------------------------
 - https://www.python.org/downloads/windows/  →  Python 3.12 (64-bit)
 - Beim Installieren UNBEDINGT den Haken "Add python.exe to PATH" setzen.
 - Prüfen: Eingabeaufforderung öffnen →  py -3.12 --version

--------------------------------------------------------------------------
 SCHRITT 2 – VB-CABLE installieren
--------------------------------------------------------------------------
 - https://vb-audio.com/Cable/  →  "VBCABLE_Driver_Pack45.zip" laden
 - ZIP entpacken → Rechtsklick auf  VBCABLE_Setup_x64.exe
   → "Als Administrator ausführen" → "Install Driver"
 - PC neu starten.

--------------------------------------------------------------------------
 SCHRITT 3 – VB-CABLE einstellen
--------------------------------------------------------------------------
 Win+R →  mmsys.cpl  → Enter

 Ist VB-CABLE aktiviert?
   - In beiden Reitern mit Rechtsklick in die Liste →
     "Deaktivierte Geräte anzeigen". Steht bei "CABLE Input" oder
     "CABLE Output" "Deaktiviert" → Rechtsklick → "Aktivieren".
   - (Die App prüft das selbst: Einstellungen → System-Check →
     "Automatisch reparieren".)

 Reiter "Wiedergabe":
   - "CABLE Input" → Eigenschaften → Erweitert
       Standardformat: 2 Kanal, 24 Bit, 48000 Hz (Studioqualität) → OK
   - "CABLE Input" → Eigenschaften → Pegel: 100, nicht stumm
   - Dein normales Ausgabegerät (Lautsprecher/Kopfhörer) bleibt
     "Standardgerät" – Aurelune schaltet beim Einschalten selbst um.
     (Ohne automatisches Umschalten: "CABLE Input" als Standard setzen.)
   - Empfohlen: Lautsprecher ebenfalls auf 48000 Hz stellen.

 Reiter "Aufnahme":
   - "CABLE Output" → Eigenschaften → Erweitert
       Standardformat: 2 Kanal, 24 Bit, 48000 Hz → OK
   - "Abhören": Haken bei "Dieses Gerät als Wiedergabequelle
     verwenden" NICHT setzen (sonst hörst du alles doppelt).

 Reiter "Kommunikation":
   - "Nichts unternehmen" auswählen → OK

--------------------------------------------------------------------------
 SCHRITT 4 – Aurelune Studio installieren
--------------------------------------------------------------------------
 Den Ordner "app" aus dem Paket z. B. nach
   C:\Users\<NAME>\AppData\Local\Programs\Aurelune Studio
 kopieren. Dann dort eine Eingabeaufforderung öffnen:

   py -3.12 -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt

 Geräte-Umschalter bauen (optional, für automatisches Umschalten):

   C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /out:AudioSwitch.exe AudioSwitch.cs

 Starten:   .venv\Scripts\pythonw.exe app.py

--------------------------------------------------------------------------
 SCHRITT 5 – In der App
--------------------------------------------------------------------------
 - Großen Kreis antippen → Aurelune ist aktiv.
 - Ohne AudioSwitch.exe: Einstellungen → "Audio-Geräte automatisch" aus
   → Eingang "CABLE Output", Ausgang = deine Lautsprecher → übernehmen.
 - Einstellungen → "Mit Windows starten" einschalten.

--------------------------------------------------------------------------
 STEELSERIES SONAR / EQUALIZER-SOFTWARE (z. B. Arctis 7+)
--------------------------------------------------------------------------
 So läuft der Ton:
   Spiele/Spotify → CABLE Input → Aurelune (432 Hz) →
   "SteelSeries Sonar - Gaming" (dein EQ) → Arctis 7+ Headset

 - Vor der Installation "SteelSeries Sonar - Gaming" als Standardgerät
   lassen – der Installer übernimmt es automatisch als Hauptlautsprecher.
 - Oder in der App: Einstellungen → "Hauptlautsprecher" →
   "SteelSeries Sonar - Gaming (…)" wählen.
 - Setzt Sonar sich selbst wieder als Standard, schaltet Aurelune nach
   ein paar Sekunden automatisch zurück auf "CABLE Input".
 - Apps, die in Windows/Sonar fest einem Kanal zugeordnet sind (z. B.
   Discord → "Sonar - Chat"), laufen an Aurelune vorbei. Sollen sie auch
   umgestimmt werden: Ausgabegerät in der App auf "Standard" stellen.

--------------------------------------------------------------------------
 DISCORD / SPIELE / SPOTIFY
--------------------------------------------------------------------------
 Ausgabegerät in der jeweiligen App auf "Standard" lassen.
 Discord: Einstellungen → Sprache & Video → Ausgabegerät "Default".

--------------------------------------------------------------------------
 BEWEIS: WIRD WIRKLICH 432 HZ ABGESPIELT?
--------------------------------------------------------------------------
 Startseite → Karte "Beweis": Aurelune misst unabhängig das Signal, das
 an deine Lautsprecher geht.
   - "Original (Eingang)" = Stimmung des Songs, z. B. 440,0 Hz
   - "Du hörst (Ausgang)" = gemessene Stimmung, z. B. 432,0 Hz
   - "Stimmungs-Fingerabdruck": die farbige Kurve liegt auf der Ziel-
     Linie, die graue (Original) auf 440.
   - "Original hören" gedrückt halten → die Messung springt auf 440.

--------------------------------------------------------------------------
 PROBLEME?
--------------------------------------------------------------------------
 Kein Ton:     Startmenü → Aurelune Studio → "Ton zurücksetzen"
               oder in mmsys.cpl deine Lautsprecher als Standard setzen.
 Doppelter Ton: bei "CABLE Output" das "Abhören" deaktivieren.
 Knackser:     Einstellungen → Profil "Musik"; alle Geräte auf 48000 Hz.
 App reagiert nicht: Installer erneut starten (installiert WebView2);
               Aurelune öffnet sich sonst automatisch im Edge-Fenster.
 Logdateien:   %TEMP%\AureluneSetup\setup.log
               %USERPROFILE%\.aurelune\aurelune.log

--------------------------------------------------------------------------
 DEINSTALLIEREN
--------------------------------------------------------------------------
 Windows-Einstellungen → Apps → "Aurelune Studio" → Deinstallieren
 (fragt auch, ob VB-CABLE entfernt werden soll).

UPDATE (ohne Neuinstallation)
-----------------------------
1. Neue Aurelune-Komplett.zip entpacken (z.B. ueber den alten Ordner).
2. Aurelune-Update.bat doppelklicken.
3. Fertig: Einstellungen, Python und VB-CABLE bleiben erhalten, die App startet neu.
   Bei einem Fehler wird automatisch die alte Version wiederhergestellt.
   Protokoll: %TEMP%\AureluneSetup\update.log
