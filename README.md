# Aurelune Studio

## Installieren / Install

**Nur `Aurelune-Studio-Setup.exe` herunterladen und starten – fertig.**
Die EXE lädt automatisch die neueste Version von GitHub und richtet alles ein (Python, VB-CABLE, Verknüpfungen).

**Just download and run `Aurelune-Studio-Setup.exe` – that's it.**
It always downloads the latest version from GitHub and sets everything up.

## Updates

Nichts zu tun: Aurelune prüft alle 3 Minuten auf GitHub (auch im Hintergrund, wenn das Fenster zu ist),
installiert neue Versionen selbst und startet automatisch neu. Abschaltbar in den Einstellungen („Automatische Updates“).

Nothing to do: Aurelune checks GitHub every 3 minutes (also in the background) and updates itself.
